Périphériques & appairage

Boutons de secours (BOOT)

Enregistrer redémarre le module (USB ré-énuméré) : reconnectez ensuite.

Appairage BLE ↔ BLE — étoile (jusqu'à 3 esclaves)

Scan de 4 s. Le module cible doit être libre (non connecté à un téléphone).
Le maître injecte clavier/souris localement (id 0) et route les GPIO par id vers l'esclave choisi. Lien d'un esclave coupé → {"err":"nolink"}.
Astuce : 5 appuis sur le bouton BOOT (< 3 s) sur le maître désappairent toute l'étoile ; sur un esclave, {"t":"pair","a":"reset"} par son port COM le libère.
